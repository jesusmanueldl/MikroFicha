MikroFicha: Genera, Administra y Vende Internet por Fichas​

Descripción: MikroFicha es una aplicación móvil para Android diseñada para generar, administrar y vender acceso a Internet mediante fichas, vouchers o tickets, especialmente para Hotspot Mikrotik en RouterBoard versiones 6+.​

Versión Actual: Framboyán v3.9.2 (Actualizada el 20 de marzo de 2025)​

Requisitos: Android 6.0 o versiones posteriores​
Descargas: Más de 5,000​
Características Principales:

Generación de más de 300 fichas con un plan de suscripción​

Creación de fichas en PDF o impresión directa de hasta 100 fichas en impresoras térmicas Bluetooth​

Conexión remota a routers Mikrotik mediante VPN sin necesidad de IP pública​

Gestión completa de planes: agregar, eliminar y editar​
Funcionalidad de tiempo corrido para evitar reinicios de tiempo en fichas​

Notificaciones en tiempo real de conexiones de fichas​

Opciones de generación de fichas con PIN o usuario y contraseña​

Personalización de PIN en mayúsculas o minúsculas​
Gráficas de monitoreo de consumo de interfaces​

Eliminación automática de fichas una vez finalizado el tiempo​

Identificación única de la aplicación mediante UUID para opciones premium​

Compartir fichas fácilmente en formato PDF​

Conexión API: La aplicación se conecta al servicio API de Mikrotik a través del puerto correspondiente. Es esencial habilitar este servicio en el router para garantizar una comunicación adecuada.​


VPN MikroFicha Cloud: MikroFicha ofrece un servicio VPN mediante WireGuard, permitiendo a los usuarios acceder y administrar sus routers Mikrotik desde cualquier lugar del mundo. Para más información sobre este servicio, contacta a hola@mikroficha.com o visita el canal de Telegram https://t.me/Mikroficha.​


Impresión de Fichas: La aplicación permite la impresión de fichas en impresoras térmicas Bluetooth, facilitando la distribución física de accesos a los clientes. Además, se pueden generar fichas en PDF para su impresión posterior o envío digital.​

Monitoreo de Interfaces: MikroFicha proporciona herramientas para monitorear en tiempo real el consumo de las interfaces de internet, incluyendo parámetros de carga (Tx) y descarga (Rx), así como velocidades de transmisión.​

Diseño Personalizado de Fichas: Los usuarios pueden diseñar sus propias fichas utilizando plantillas disponibles, adaptándolas a las necesidades específicas de su negocio. Se ofrece un molde en PowerPoint para facilitar la personalización.​

📌 ¿Qué es MikroFicha?
MikroFicha es una aplicación móvil diseñada para generar, administrar y vender fichas de acceso a Internet utilizando routers MikroTik. Su objetivo principal es facilitar la gestión de usuarios en redes hotspot mediante tickets, pines o vouchers personalizados.

FUNCIONALIDADES PRINCIPALES
=======================

✅ Generación de Fichas:

✅ Exportación e Importación:
- Puedes exportar tus fichas en PDF o enviarlas por WhatsApp, correo, etc.

PREGUNTAS FRECUENTES

❓ ¿Cómo agregar un nuevo plan?
→ Desde el menú "Planes", pulsa "+" y define el nombre, duración y perfil MikroTik.

===========================

📌 Descripción general:
MikroFicha genera códigos o identificadores únicos conocidos como PIN para ser usados como usuario y contraseña en las fichas de acceso a Internet.

🧩 Composición del PIN o Contraseña:
El PIN está compuesto por una combinación alfanumérica estructurada de la siguiente manera:

- Esta estructura está diseñada para ofrecer un equilibrio entre seguridad y facilidad de uso para el usuario final.

- Las letras pueden generarse en mayúsculas o minúsculas, dependiendo de la configuración elegida por el usuario.

🗝 Usos del PIN o Contraseña:
- Este PIN sirve tanto como identificador de usuario como contraseña, cuando se selecciona ese método de generación.
- Se utiliza principalmente en redes hotspot gestionadas por routers MikroTik.

📎 Consideraciones:
- La generación del PIN es aleatoria, lo que garantiza que cada ficha tenga un identificador único.
- Esta aleatoriedad contribuye a la seguridad del acceso a la red.

Tiempo Corrido (en Mikrotik Hotspot):
=======================
 Tiempo Corrido (en Mikrotik Hotspot):
Es el tiempo total que un usuario puede estar conectado, sin importar si se desconecta o no.

Empieza a contar desde que el usuario se conecta por primera vez, y sigue corriendo aunque el usuario cierre sesión o apague su dispositivo.

Ejemplo: Si configuras 1 hora de tiempo corrido, el usuario solo podrá usar esa cuenta por 1 hora total, aunque se haya conectado solo 10 minutos hoy y quiera conectarse mañana.

=======================
Tiempo Pausa (o "Uptime"):
=======================

Es el tiempo efectivo de uso, solo cuenta cuando el usuario está conectado activamente al hotspot.

Ejemplo: Si asignas 1 hora de tiempo pausa, el usuario puede usar esa hora en sesiones separadas (10 min hoy, 20 min después, etc.) hasta acumular 1 hora de conexión real.

🟡 Diferencia Clave:
Tiempo Corrido es un tipo de tiempo que sigue avanzando aunque el usuario esté desconectado. Es decir, desde el momento en que el usuario inicia sesión por primera vez, el reloj empieza a correr y no se detiene, aunque el usuario apague su dispositivo o se desconecte del hotspot. Por ejemplo, si le das 1 hora de tiempo corrido a una cuenta, esa hora se va a consumir aunque el usuario solo se conecte unos minutos. Al terminar esa hora, la cuenta ya no servirá.

Tiempo Pausa, en cambio, solo cuenta el tiempo cuando el usuario realmente está conectado. Si el usuario se desconecta, el tiempo se detiene. Por ejemplo, si le das 1 hora de tiempo pausa, esa hora se va descontando únicamente mientras el usuario esté navegando. Puede usar 10 minutos hoy, 20 mañana y así hasta agotar el total de 1 hora.

¿Qué es IP Binding en Mikrotik Hotspot?
=======================

IP Binding es una función del Hotspot de Mikrotik que permite asignar reglas especiales a dispositivos específicos (por su IP o MAC address), saltándose el portal cautivo o aplicando restricciones específicas.

🔸 ¿Para qué se usa IP Binding?
Bypass (omitir el login del hotspot): Algunos dispositivos pueden navegar sin autenticarse, por ejemplo:

Cámaras de seguridad

Impresoras de red

Equipos del administrador

Bloquear acceso a ciertos dispositivos por IP o MAC.

Aplicar reglas específicas sin necesidad de pasar por el sistema de usuarios del Hotspot.

🔸 Tipos de IP Binding:
Tipo	¿Qué hace?
bypassed	El dispositivo se salta el login del hotspot y navega libremente.
blocked	El dispositivo no puede acceder a Internet, aunque esté conectado.
regular	No hace nada especial. Es solo informativo o para organización.
✅ Ejemplo:
Supón que tienes una cámara con IP 192.168.88.10 y no quieres que el hotspot le pida usuario y contraseña:

Vas a IP > Hotspot > IP Bindings.

Agregas una nueva entrada:

Address: 192.168.88.10

Type: bypassed

Y listo, esa cámara ya no pasará por el portal cautivo.
